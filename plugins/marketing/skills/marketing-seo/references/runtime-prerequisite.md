## Readiness and consent

- Require shell/Bash and Python 3.11–3.14, venv/ensurepip and the original
  managed dependency environment. `uv` alone does not satisfy runtime setup.
- With authorization for diagnosis run the quoted resolved executable with
  `doctor --json`; distinguish core readiness from `browser_ready`. Require
  Playwright/Chromium for rendered/visual operations. Reports may additionally
  need WeasyPrint/Pango/fonts; optional page-count checks may need pypdf.
  The upstream optional Google logo is absent: do not download or promise it.
- Missing dependencies block the selected operation, not knowledge use.
  Setup, installers, package downloads, browser installation, OAuth and account
  configuration are separate mutations requiring explicit approval. No automatic
  global/user pip fallback, no upstream-script execution merely to inspect it.
- Confirm actual provider schemas and scoped secret references before calls.
  A method's lexical tool name is not proof that the host exposes that tool.
  DataForSEO uses original dataforseo-mcp-server@2.8.10 (Node >=20, npx,
  configured username/password and original field config); check cost, obtain
  required approval, respect budget and log actual cost for each paid call.
  This pin has no Google Images SERP tool. Merchant REST is only the explicitly
  documented ecommerce operation, not a bypass of an unavailable MCP tool.
- Google PSI/CrUX disclose URL/origin; GSC/GA4 read private property data;
  NLP discloses page text. Consent must cover the selected disclosure. Index,
  sitemap/GBP writes and OAuth token creation need separate authorization.
  Never expose keys, tokens, account IDs or copy credential configuration.
- Moz/Bing/Keywords Everywhere disclose domains/URLs; Bing comparison needs
  both properties in the same authorized account. Moz's fcntl dependency
  needs operation-specific platform support. Free Common Crawl/target requests
  are still network actions, not offline knowledge.
- Optional Matomo, Firecrawl, Ahrefs and Banana bindings are not installed by
  selecting this skill. Verify the exact supported host tool schemas and data
  destinations; only use source-documented fallback, otherwise report blocked.
  Matomo data stays with the selected instance; Banana generation shares prompts
  and reference images with Google and requires an explicit paid asset request.
- SSRF and DNS-rebinding guards stay enabled; never replace guarded fetch/render
  with a permissive client. A local target requires its exact operator-approved
  scoped allowlist, never general access to private networks. User-agent/WAF
  probes need explicit site testing authorization.
- Host HOME/config/cache paths can be shared: runtime data-dir isolation does
  not prove credential/cache isolation. Keep ledgers, SQLite, reports, captures
  and client data private. Do not create schedules or reset budget state.
