## Imported knowledge and rights

The 39 imports add 26 claude-seo knowledge entries, 12 LinkedIn workflows and
one email-marketing manual. `marketing-on-page-seo-implementation` remains the
implementation owner; SEO assessment entries hand implementation findings to it.

The SEO entries do not bundle or install the original claude-seo runtime. Before
operations, separately resolve and verify the original runtime and actual host
bindings using each entry's Working mode contract and, where packaged,
`references/runtime-prerequisite.md`. Slash-command
examples and agent names are source interfaces, not automatically registered
commands, native agents or tool grants. Provider, browser and runtime compatibility
is not certified. Missing dependencies block operations, not reading knowledge.
LinkedIn provider and private-context bindings are described in each imported
entry's `DEPENDENCIES.md`; email ESP bindings, consent, suppression and explicit
send approval remain required. No sending or account configuration is enabled.
The email package's archived upstream plugin metadata and nested entry are inactive
source provenance, not additional plugins or discovery entrypoints.

Aggregate package license: `MIT AND CC-BY-4.0`. This describes separate
components, not a relicensing or a choice of license for every file. See the
[third-party rights guide](../../docs/third-party-licenses.md) and each imported
entry's `ORIGIN.md`, full `LICENSE` and applicable notices.
